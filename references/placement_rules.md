# 引用插入位置与样式细则

## 1. 需要来源支撑的句子类型

- 具体数值、比率、性能指标（"效率达到 34%"）。
- 具体事实性结论（"X 被证实可抑制 Y"）。
- 对他人方法、模型、数据集的指称（"采用 Z 等人提出的方法"）。
- 领域现状陈述（"近年来……受到广泛关注"）。
- 争议性或对比性论断（"A 优于 B"）。

不需要引用：常识性定义、本文自己的工作陈述、过渡句。

## 2. 插入位置

- 顺序编码制：编号置于论断句末标点**之前**，上标样式由排版端处理，稿件中写作 `[n]`。例如：

  > 钙钛矿-硅叠层电池效率已超过 34%{cite:e0012}。

- 一句多引：同一论断由多条文献共同支撑时并列，如 `[3,5-7]`，占位符写法 `{cite:e0003,e0005,e0006,e0007}`。
- 多句一引：连续多句依赖同一文献时**逐句**标注，不只在最后一句标注。
- 人名主导句（"Zhang 等[4]提出……"）：编号紧跟人名之后。

## 3. 禁止位置

- 段落末尾一次性堆叠整段引用（段内各句论断来源不同会张冠李戴）。
- 图注、表注中作为正文论断的替代标注；图表来源另有说明时应注明"改绘自[n]"或"数据来自[n]"。
- 章节标题中。

## 4. 著者—出版年制

- 正文形式：`(Zhang 等, 2020)` / `(Smith & Jones, 2019)` / `(Li et al., 2021; Wang et al., 2022)`，同组多引用分号分隔并按年份排序。
- 使用本 Skill 的 `renumber --mode author-year --keymap keymap.json` 做一致性校验。keymap 由你（Agent）生成，格式：

```json
{
  "Zhang 等, 2020": "e0003",
  "Smith & Jones, 2019": "e0007"
}
```

- 文末列表按第一著者字母（或拼音）升序排列，脚本 `format` 输出后人工排序，或改用 `--style gbt7714` 生成条目文本后按著者排序。
- 同一著者同年多篇：在年份后加 a/b/c 区分，并在文末列表同步。

## 5. 编号重排触发场景

以下任一情况发生后必须重跑 `renumber` + `format` + `check`：插入新引用、删除引用、章节调序、合并/拆分条目。重排是连锁的：正文编号、文末列表序号、图表注中的编号同时更新，禁止只改一处。

## 6. 数字标记的安全识别（renumber 模式）

`renumber` 按上下文把 `[n]` 类标记分为三类，只有 citation 会被改写：

- **citation**：紧贴文字（中文或西文）之后的 `[n]`，或西文空格分隔的 `[n]`，编号 1—999。
- **ambiguous**（保留原文并列入报告，交人工确认）：行首的 `[n]`；`=`、`+`、`(` 等操作符之后的 `[n]`（数学语境）；含 0 或大于 999 的编号（区间 `[0,1]`、年份 `[2020]`）；中文语境下空格分隔的 `[n]`（多为公式/图表编号，如"公式 [3]"）。
- **skip**：Markdown 链接 `[1](url)`、LaTeX 转义 `\[`。

图表注、脚注、附录中的引用按正文同规则处理；被判定 ambiguous 的标记不得擅自改写，逐条列入 `renumber_report.json` 的 `ambiguous_markers_untouched` 并在 result.json 的 `needs_human_review` 中说明。
